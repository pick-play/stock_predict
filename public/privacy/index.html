개인정보처리방침

시행일: 2026년 8월 31일

코스피 NOW(kospinow.com, 이하 "서비스")는 이용자의 개인정보를 최소한으로 수집하는 것을 원칙으로 하며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 이 방침은 서비스가 어떤 정보를 왜 수집하고, 얼마나 보관하며, 이용자가 어떤 권리를 갖는지 설명합니다.

1. 수집하는 정보

회원가입 시 (선택 — 가입하지 않아도 시세 확인과 채팅 참여가 가능합니다)

  • 닉네임 — 게시판·채팅에서의 표시 이름입니다.
  • 비밀번호 — 원문은 저장하지 않습니다. 브라우저에서 1차 암호화된 값이 전송되고, 서버는 여기에 다시 이용자별 무작위 값을 결합해 해시로만 저장합니다. 운영자를 포함해 누구도 비밀번호 원문을 볼 수 없습니다.
  • 복구 코드 — 가입 시 한 번 발급되며 해시로만 저장합니다.
  • 이메일 주소, 전화번호, 실명, 생년월일 등 실명 식별 정보는 수집하지 않습니다.

서비스 이용 과정에서 자동으로 처리되는 정보

  • IP 주소 — 원본 IP 주소를 저장하지 않습니다. 도배·남용 방지와 접속자 수 집계를 위해, 하루 단위로 바뀌는 값과 결합한 일방향 해시만 처리합니다. 이 해시는 다음 날이면 같은 IP라도 다른 값이 되며, 원본 IP로 되돌릴 수 없습니다.
  • 작성 콘텐츠 — 게시글, 댓글, 채팅 메시지. 채팅은 최근 500개만 순환 보관하며 오래된 메시지는 자동 삭제됩니다.
  • 로그인 세션 — 로그인 상태 유지를 위한 무작위 토큰(해시로 저장, 30일 유효).
  • 출석 정보 — 로그인 회원의 마지막 방문일, 누적·연속 방문일수.
  • 브라우저 저장소(localStorage) — 화면 테마 선택, 로그인 세션, 안내 배너 닫음 여부 등 편의 설정. 이 값들은 이용자의 브라우저에만 저장됩니다.

2. 이용 목적

  • 로그인, 글·댓글 작성 등 회원 기능 제공
  • 도배, 욕설, 광고 등 남용 방지와 이용 제한
  • 접속자 수 집계 등 서비스 운영에 필요한 통계
  • 서비스 개선을 위한 방문 통계 분석(Google Analytics)
  • 광고 게재(Google AdSense)

4. 제3자 제공 및 처리 위탁

서비스는 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 서비스 운영을 위해 다음 외부 서비스를 이용하며, 이 과정에서 접속 정보가 해당 사업자에 전달될 수 있습니다.

  • Cloudflare — 채팅·게시판 서버와 데이터베이스 호스팅, 자동 입력 방지(Turnstile)
  • GitHub — 웹 페이지 정적 호스팅
  • Google — 방문 통계(Google Analytics), 광고(Google AdSense)
  • 외부 시세 제공자 — 시세 표시를 위해 이용자의 브라우저가 해외 시세 제공자의 공개 API에 직접 접속합니다. 이때 통상적인 통신 정보(IP 주소 등)가 해당 제공자에 전달됩니다. 서비스가 별도의 개인정보를 함께 보내지는 않습니다.

5. 쿠키와 맞춤 광고

Google을 포함한 제3자 광고 사업자는 쿠키를 사용해 이용자의 이전 방문 기록을 바탕으로 광고를 게재할 수 있습니다. Google의 광고 쿠키 덕분에 Google과 그 파트너는 이용자의 본 서비스 및 다른 웹사이트 방문 기록을 기반으로 광고를 제공할 수 있습니다.

이용자는 Google 광고 설정에서 맞춤 광고를 해제할 수 있으며, www.aboutads.info에서 다른 제3자 광고 사업자의 쿠키 사용도 해제할 수 있습니다. 브라우저 설정에서 쿠키 저장을 거부할 수도 있습니다(일부 기능이 제한될 수 있습니다).

6. 이용자의 권리

  • 본인이 작성한 게시글·댓글은 직접 삭제할 수 있습니다.
  • 계정 삭제, 본인 관련 정보의 열람·삭제 요청은 아래 문의처로 연락해 주세요. 확인 후 지체 없이 처리합니다.
  • 실명 식별 정보를 수집하지 않으므로, 요청 처리 시 계정 소유 확인을 위해 닉네임과 복구 코드 등의 확인을 요청할 수 있습니다.

7. 안전성 확보 조치

  • 비밀번호는 브라우저와 서버에서 이중으로 해시 처리되어 원문이 어디에도 저장되지 않습니다.
  • 원본 IP 주소를 저장하지 않고 일 단위로 변하는 일방향 해시만 사용합니다.
  • 모든 통신은 HTTPS로 암호화됩니다.
